# 家族タスク (family-task-app)

夫婦2人用のタスク管理アプリです。React + Vite + Tailwind CSS + Supabase。

- 準備: Supabase の SQL Editor で `supabase/01_schema.sql`、`supabase/02_members.sql` の順に実行
- 開発: `npm install` → `npm run dev`
- 公開: `main` に push すると GitHub Actions が GitHub Pages に公開（Settings > Pages > Source は「GitHub Actions」）
